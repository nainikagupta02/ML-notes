## Add a note

1. Create a Markdown file in `notes/`, such as `linear-regression.md`.
2. Write your explanation, equations, examples, and references.
3. Add a link to the new file in the [notes index](notes/README.md).

On GitHub, open the `notes` folder and choose **Add file → Create new file**, or upload an existing Markdown file or PDF.

GitHub renders LaTeX math using `$...$` for inline equations and `$$...$$` for display equations.

These are personal learning notes and may contain mistakes or evolve as my understanding develops.
